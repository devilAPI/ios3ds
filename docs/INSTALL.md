# Installing ios3ds

The install guide is now part of the README: **[README.md → Install](../README.md#install)**

(Online: <https://github.com/devilAPI/ios3ds#install>. In a release zip, it is the *Install* section of `README.md` next to this file.)

For the experimental 4.1, 3.1.3 and 2.2.1 installs (`install.py --ios VERSION`),
see **[docs/other-versions.md](other-versions.md)** in this zip. Everything
other than 4.2.1 is highly experimental, emulator-only and may not boot.
